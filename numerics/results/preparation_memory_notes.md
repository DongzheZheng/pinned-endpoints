# Prepared spectra and entropy-Galerkin shape reconstruction

The figure uses d=0.008, M=14, n=768 and preparation amplitude eta=0.1. Its left panel shows the analytic positive initial spectra W_plus/minus=N_d +/- eta*N_d^2*sin(2x). By parity, both spectra exactly have the action and energy densities of N_d. Their full initial wave entropies are equal because W_minus(x)=W_plus(-x). The right panel displays g_plus(x,t)/eta reconstructed from the full finite Galerkin propagator; it is not a single-exponential fit. The zero relative distortion is the equilibrium N_d. The opposite preparation has exactly the opposite linear distortion.

The single reference collision and entropy-mass matrices were recomputed with the existing `numerics/endpoint_spectrum.py` functions. The exact-invariant projected basis was reconstructed using the same 65,536-point periodic Gram integration as the original mass. All 27 generalized eigenvectors, the projection coefficients, matrix pair, mode amplitudes, time coefficients and full wave/time grid are stored in `preparation_memory_galerkin.npz`. Configuration, source hashes and checks are in `preparation_memory_metadata.json`. Original CSV data were not modified.

The recomputed rates, normalized sin(2x) weights and slow-time moment response agree exactly with the stored original values in this run. The largest initial-shape error is 1.55e-15. The normalized quadratic entropy deficit obeys ||g(t)||^2/||g(0)||^2=C2(2t); its matrix identity check has maximum error 1.33e-15. The computed action and energy changes over tau in [0,3] are at most 1.78e-18 and 3.41e-19. The shown linear occupations are positive, with minimum 0.89549. These floating-point checks validate this finite reconstruction, not an infinite-dimensional or nonlinear evolution theorem.

The two-panel moment/entropy response figure uses only the original rates and weights, evaluating C2(t) and C2(2t) directly. Its dotted and dashed comparison curves are the original and adjusted trial bounds in the limiting slow-time variable; the entropy-panel exponents are doubled. They are limiting lower-bound curves, not finite-d pointwise estimates or fitted evolution laws. The entropy-response axis displays the normalized quadratic norm directly; it does not display the full nonlinear entropy at eta=0.1.

Regenerate the spectrum data with `OPENBLAS_NUM_THREADS=1 python scripts/preparation_memory.py`. Redraw all current figures from saved data with `OPENBLAS_NUM_THREADS=1 python scripts/manuscript_figures.py`. Only the first command performs the single reference resonance integration.

The recorded NPZ is unchanged. Regenerated outputs go to `generated/results` and `generated/figures`, or the `PINNED_RESULTS_DIR` and `PINNED_FIGURES_DIR` directories.
